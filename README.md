Amusement Park Ticket Billing System

About the Project

A Python program that calculates amusement park ticket charges based on visitor height and age, with an optional photography service.

Features

- Checks ride eligibility based on visitor height.
- Calculates ticket charges according to age groups.
- Provides an optional photography service.
- Adds additional charges to the final bill.
- Displays the total amount payable.

Technologies Used

- Python

How to Run

1. Download the "amusement_park_billing.py" file.
2. Run it using Python.
3. Enter the visitor's height and age.
4. Choose whether to include the photography service.
5. View the final ticket bill.
